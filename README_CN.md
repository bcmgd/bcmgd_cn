# bcmgd.cn
我的个人网站

> 🌐在线访问：**https://bcmgd.cn**

## 📂项目结构
- `friends/` — 友情链接页面
  - `index.html`
- `projects/` — 项目汇总页
  - `index.html`
  - `me.jpg`
  - `download/` — 资源下载子页面
    - `index.html`
    - `xkyt.html`
    - `xmdb.html`
    - `gun.webp`
    - `中文命令行2.1.0.zip`
- `index.html` — 网站首页

## ✨网站内容
- 🏠首页：个人介绍
- 🤝friends：友情链接
- 📁projects：个人项目集合
  - download：资源下载区，存放自制程序与素材
  - xkyt / xmdb：独立小项目页面

## 🛠技术栈
纯静态网页，无前端框架
- HTML5
- CSS
- JavaScript

## 🚀本地运行
直接在浏览器打开根目录 `index.html`，即可预览完整网站。
> 不需要启动Web服务器。

## 📦部署
源码托管在GitHub，可使用各类静态网页托管服务部署。
